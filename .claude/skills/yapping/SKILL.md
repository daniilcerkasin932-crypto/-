# Yapping

## Overview

Create talking-head scripts that sound like a person with a strong point of view, not a polished essay. Use this repeated chain:

```text
hot take -> actionable value -> loop move
```

Loop move means either an **open loop** that pulls the viewer into the next beat, or a **closed loop** that pays off a promise already made.

## Workflow

1. Define the audience and the uncomfortable belief. If everyone would politely agree, sharpen it.
2. Turn the belief into a hot take: a contradiction, warning, confession, or opinion worth arguing with.
3. Add actionable value: a behavior, checklist, exercise, diagnostic, or rule the viewer can use today.
4. Add the loop move:
   - **Open loop:** tease the next beat without giving it away.
   - **Closed loop:** answer the exact question or tension created earlier.
5. Repeat the chain. Each new hot take should escalate, contradict common advice, or reframe the last value point.
6. Close the main loop before the CTA.

## Quick Reference

| Part | Job | Strong version | Weak version |
| --- | --- | --- | --- |
| Hot take | Create tension | "Your AI videos are making you forget how to be interesting." | "AI videos have pros and cons." |
| Actionable value | Give usable next step | "Write 10 opinions you would defend in a comment war." | "Have more opinions." |
| Open loop | Create the next question | "But do not record them until you filter for this one thing." | "And there is more." |
| Closed loop | Pay off the promise | "The filter is: would this make someone stop scrolling to argue or steal it?" | "That is the secret." |

## Output Shape

Use this compact structure unless the user asks for another format:

```markdown
Audience:
Main tension:

Block 1:
- Hot take:
- Actionable value:
- Loop move:

Block 2:
- Hot take:
- Actionable value:
- Loop move:

Block 3:
- Hot take:
- Actionable value:
- Loop move:

Final payoff:
CTA:
```

For Ukrainian content, write natural Ukrainian. Do not translate English creator slang word-for-word if it sounds fake. Profanity is allowed only when it fits the creator's voice or the user explicitly wants that level of aggression.

## Example

```markdown
Audience:
Founders who hide behind AI-generated videos because recording themselves feels awkward.

Main tension:
AI can speed up content, but it can remove the human signal that makes people care.

Block 1:
- Hot take: AI videos are making your content easier to produce and easier to ignore.
- Actionable value: Record one raw 30-second take where you say the opinion you usually soften.
- Loop move: But do not post it yet; the first take is usually missing one retention trigger.

Block 2:
- Hot take: Your camera confidence is not the problem; your opinion has no edge.
- Actionable value: List 10 beliefs your audience might argue with, then pick one you can prove from experience.
- Loop move: The proof is what separates useful controversy from empty noise.

Block 3:
- Hot take: If nobody could disagree with your video, nobody has a reason to watch you explain it.
- Actionable value: Use: "Most people do X, but I do Y because Z."
- Loop move: Closed loop: that line gives you the take, value, and next unanswered question.

Final payoff:
Yapping works when every beat makes a bold claim, gives a usable move, or opens a reason to hear the next sentence.

CTA:
Follow for scripts that sound like a person, not a content calendar.
```

## Quality Check

Before finalizing, verify:

- The first line contains a real opinion, contradiction, or uncomfortable claim.
- Every block has all three parts: hot take, actionable value, loop move.
- The actionable value can be done by the viewer today.
- Open loops create a specific unanswered question.
- Closed loops pay off the exact question opened.
- The script sounds speakable on camera, with short sentences and clean transitions.
- The ending pays off the main tension before asking for engagement.

## Common Mistakes

| Mistake | Fix |
| --- | --- |
| Writing generic tips | Convert the first tip into a polarizing belief. |
| Revealing the answer immediately | Move the exact answer to a closed loop later. |
| Using fake suspense | Define the hidden answer first, then tease that specific answer. |
| Making the hot take mean-spirited | Attack the behavior, assumption, or strategy instead of the viewer. |
| Giving value with no personality | Add lived proof, a result, or a contrarian reason. |
| Ending with only "follow for more" | Close the loop, then add CTA. |
